About MedCom

MedCom is a multilingual medical communication web application designed to reduce language barriers between patients and healthcare staff. The system supports structured, phrase-based communication in situations where the two parties do not share a common language.

Instead of relying on unrestricted machine translation, MedCom uses predefined medical phrases and word entries stored in local structured data files. This helps create more predictable, consistent, and understandable communication in healthcare settings.

Main Features

Dual Language Selection
Patient and staff can independently choose their preferred languages.
Phrase Categories
Medical phrases are organized by category for fast and structured browsing.
Structured Translation Display
The selected phrase is shown in both the patient’s and the staff’s chosen languages.
Smart Search
Users can type or speak keywords to receive relevant phrase suggestions.
Word Lookup
The app includes a searchable multilingual word list for quick vocabulary clarification.
Recent Phrases
The five most recently selected phrases are stored for quick reuse.
Audio Playback
Some phrases can be played as recorded audio, with browser speech fallback when needed.
Admin Management
Authorized administrators can add and delete phrases and words without changing application code.

How MedCom Works

The user first selects a language for the patient and a language for the healthcare staff. After that, phrases can be browsed by category or found through smart search. When a phrase is selected, the system displays the same phrase meaning in both selected languages.

The system also supports word lookup, recent phrase history, and optional audio playback. Administrative functions make it possible to maintain and extend the phrase and word datasets without changing the application logic.

Technical Overview

MedCom is implemented as a Flask-based web application with a browser-based frontend. The system uses HTML, CSS, and JavaScript in the user interface, while structured JSON files are used to store languages, phrases, keywords, and word entries.

The architecture separates presentation, application logic, and data, which supports maintainability and easier content updates. The local-first data approach also supports controlled operation without relying on external translation APIs.

Important Notes

MedCom is intended to support structured multilingual communication in healthcare contexts. It is not designed to replace professional interpreters in complex or sensitive medical situations.

The current version is a project-based prototype focused on usability, clarity, and maintainability. It is best suited for controlled environments where a small-scale and predictable communication tool is needed.
